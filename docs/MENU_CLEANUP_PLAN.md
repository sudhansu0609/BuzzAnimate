# Menu clean-up: one way in for each thing

User, 2026-11-04: "why we have import to stage, import to library, import image, import sound? only import to stage and import to library shall be there and it shall handle both image and sound. and why so many different places of AI? trace, layer, all shall be one place. don't want so many different menus doing same things."

Rule from now on: **one menu entry per job**. A command may still have a shortcut, an agent/API name and a context-menu entry, but it appears in **one** menu, and two entries never do the same job.

## What is duplicated today (Opus, from `crates/buzz-ui/src/panels.rs` `menu_bar` and `app.rs` `stage_context_menu`)

| Job | Where it is today | After |
|---|---|---|
| Import a picture | File ▸ Import Image… (`ImportImage`); Import to Stage/Library do **not** accept pictures (`import::IMPORTABLE` = fla, xfl, swf, pdf, ai) | File ▸ Import to Stage… / Import to Library… take pictures |
| Import a sound | File ▸ Import Sound… (`ImportSound`); Import to Stage/Library already take sound (both put it in the library **and** on the timeline) | Stage: library + timeline (as now); Library: library only |
| AI for episodes | File ▸ AI ▸ New Episode, Story to Screenplay, Casting, Produce Episode | AI menu |
| Trace | Modify ▸ Bitmap ▸ Trace Bitmap…, Trace as Line Art, Trace Bold + Split into Layers | AI ▸ Trace Picture… (the Trace dialog; Line Art is a preset in it) |
| Trace + split | Modify ▸ Bitmap ▸ Trace Bold + Split into Layers; right-click ▸ Trace Bold + Split; AI ▸ Split Picture into Layers (which already traces a raw picture first) | AI ▸ Split Picture into Layers only |
| Direct a story | Scene ▸ Direct a Story… (`DirectScene`, Story panel) and AI ▸ Direct Story with LLM… (`AiDirectStory`) | both in the AI menu, side by side (one later, if the user wants) |
| Rig / name layers | Modify ▸ Timeline ▸ Rig Head, Rename Body Layers, Rename Face Layers; AI ▸ Auto-Rig, Rig Character as Layers | AI menu (only those that use a model) |

The AI panel (Window) stays as a panel; it is not a menu.

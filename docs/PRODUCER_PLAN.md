### P1 — Script breakdown (`crates/buzz-ai/src/breakdown.rs`, new)

Reads a `buzz_act::screenplay::Screenplay` and answers what the casting file
asks by hand today. Two passes through `Llm::chat_json` (model = the
configured chat model; `use_claude()` picks the Claude proxy as elsewhere), with
a deterministic offline fallback used whenever the LLM is down or answers
badly (the producer must never stop on a bad answer).

```rust
pub struct Breakdown { pub title: String, pub characters: Vec<CharacterBrief>, pub scenes: Vec<SceneBrief> }
pub struct CharacterBrief { pub name: String /* as the script writes it */, pub aliases: Vec<String>, pub description: String /* one sentence: age, build, clothes, mood — for a character-sheet prompt */, pub voice_only: bool, pub importance: u8 /* 1 lead … 3 extra */ }
pub struct SceneBrief { pub number: u32, pub slugline: String, pub interior: bool, pub setting: String /* daylight|sunset|night|interior|storm */, pub location_key: String /* snake_case; the same place in different scenes gets the same key, so one background serves them */, pub background_prompt: String /* 2–4 sentences of what the camera sees, no people, time of day, mood; comic/painterly decided by style */, pub present: Vec<String>, pub absent: Vec<String>, pub place: BTreeMap<String, f64> /* feet x 0.15..0.85 */, pub enter: BTreeMap<String, String> /* left|right */, pub props: Vec<String> /* words for the asset index: "tea stall", "charpoy" */, pub lighting: Lighting { key: String /* sun|lamp|moon|window|none */, from: String /* left|right|front */, warm: bool }, pub shots: Vec<ShotBrief> { at_line: usize /* index among the scene's dialogue lines */, kind: String /* wide|medium|close */, on: String /* character */ }, pub mood: String }
pub struct BreakdownHints { pub style: String, pub known_characters: Vec<String> /* Cast folder names */, pub series: String }
pub fn breakdown(llm: &dyn Llm, model: &str, play: &Screenplay, hints: &BreakdownHints, progress: &mut dyn FnMut(&str)) -> Breakdown  // never Err: falls back per scene
pub fn breakdown_offline(play: &Screenplay, hints: &BreakdownHints) -> Breakdown
pub fn casting_value(b: &Breakdown, cast_names: &BTreeMap<String, String> /* script name → Cast rig name */) -> serde_json::Value  // the exact `buzz_app::episode::Casting` JSON (characters with cast/voice_only/aliases, scenes with setting, place, enter, absent, props as index words under "props_wanted", plus "location", "background_prompt", "lighting", "shots" which the producer and P5 read)
```

Pass 1 (whole script, once): characters (names, aliases, descriptions,
voice-only). Pass 2: scenes in batches of 4 with the scene text verbatim.
Offline fallback: `episode::setting_for`-style slugline rules, present =
speakers + names in action lines, place spread evenly 0.25..0.75 in order of
first line, location_key = slugline place words, background_prompt = slugline
+ first action line, lighting by setting, shots = wide only.
Headless proof: `examples/breakdown.rs --script <txt> [--offline] --out <json>`
on `B:\youtubeProjects\Originals\series\ep1\script.txt`; the planner reads
the JSON. Touches nothing outside `buzz-ai` (+ `lib.rs` `pub mod`), one new
example.

### P2 — Audio: utterances → lines, scene soundtracks, audio lip sync

`crates/buzz-act/src/audio_align.rs` (new) + a hook in `buzz_app::episode`.

```rust
pub struct SpokenRef { pub scene: u32, pub item: usize /* index into ScriptScene.items */, pub words: usize }
pub struct AudioLine { pub scene: u32, pub item: usize, pub start: f64, pub end: f64 /* seconds in the recording */ }
pub struct AudioPlan { pub path: PathBuf, pub lines: Vec<AudioLine>, pub scene_spans: BTreeMap<u32, (f64, f64)> /* first line start − lead-in … last line end + tail, never overlapping the next scene */, pub notes: Vec<String> }
pub fn utterances(clip: &Clip) -> Vec<(f64, f64)>   // detect_phrases, merge gaps < 0.25 s, drop < 0.3 s
pub fn align(lines: &[SpokenRef], utts: &[(f64, f64)], transcript: Option<&[buzz_ai::transcribe::Segment]>, llm: Option<(&dyn Llm, &str)>) -> Vec<AudioLine>
```

Alignment: monotone DP between utterances and lines (one utterance may cover
several consecutive lines — split it by word share; several utterances may be
one line — merged). Cost without a transcript = |ln(utterance s / expected s)|
with expected = `Timing::per_word × words` (+ hesitation/emphasis). With a
transcript the LLM is asked once per scene to map segments to line indices
(monotone, JSON), token similarity is the fallback. Whisper runs only when
`installed_whisper()` is Ok; Hindi on base.en is weak, so the duration DP is
the working path and the plan says which path was used. A line with no audio
keeps its text timing and the report says so.

Episode hook: `BuildOptions.audio: Option<Arc<AudioPlan>>` (buzz-act does the
alignment, buzz-app owns the plan). In `build_scene`, when the plan has lines
for this scene: the schedule's line slots come from the audio (scene frame 0
= span start), action items keep their text lengths squeezed between lines;
the scene's audio is cut `[span]` to a WAV in memory → `Scene::add_sound` +
a `Sound` layer with `SoundRef::stream` at frame 0; mouths from
`analyse_visemes` on the cut clip: for each line, the speaker's mouth gets the
viseme track over its frames (closed elsewhere) through the existing writers
(`write_layer_rig_mouth` / `write_rig_mouth` / `write_track`) instead of
`textsync`. `episode_build` gets `--audio <file>` (+ `--audio-dir <dir>`
with one file per scene named `scene<N>.*`). Proof: the planner makes test
audio (Windows TTS per line of Ep1 scene 4, joined) and checks line starts
against the known timings (± 0.25 s) and that the mouth moves over each line
in stills. Touches: `buzz-act` (new file + `lib.rs`), `episode.rs`
(`BuildOptions`, the schedule and mouth passages only), `episode_build.rs`.

### P3 — Backgrounds from ComfyUI (`crates/buzz-app/src/comfy.rs`, `backdrop.rs`, new)

`comfy.rs`: `ComfyClient { base_url }` with `discover()` (`COMFYUI_URL`, then
`127.0.0.1:8188..8208` probing `/system_stats`, 0.5 s each), `ensure_running(launch: bool, wait: Duration)` (when nothing answers and `launch`: start
`run_nvidia_gpu.bat` in `COMFYUI_DIR`, default
`B:\ComfyUI_windows_portable_nvidia_cu118_or_cpu\ComfyUI_windows_portable`,
detached, `CREATE_NO_WINDOW`, then poll ≤ wait), `queue(workflow: Value) -> prompt_id`
(`POST /prompt`, 120 s), `wait(prompt_id, timeout) -> Vec<Output{filename, subfolder, kind}>`
(poll `/history/{id}` every 1 s; connection refused for > 20 s = failed;
read every `images` entry), `view(output) -> Vec<u8>` (`GET /view`). Only
localhost URLs; no `Origin` header. Mirrors BuzzEdit's Python client.

`backdrop.rs`:
- `workflow_path()` = `<estate>/BuzzEdit/workflows/zimage1_hq.json` (else
  `zimage1.json`; the estate root from `buzz_app::estate::estate_root()`,
  else `COMFY_WORKFLOWS` env). Never copied into the repo. Bind node `70`
  `inputs.text`, `66` width/height, `69` seed (+ `hires` seed when present),
  `9` filename_prefix `buzzanimate-bg`. Base 1280×720; the hq workflow's 1.5×
  pass gives 1920×1080.
- `pub struct Style { pub name: String, pub suffix: String }` with two presets:
  `Style::comic()` = "2D animation background art for a light-hearted comic
  series, professional illustration, clean confident line work, flat cel
  colours with soft gradients, simple readable shapes, warm cheerful palette"
  and `Style::painterly()` = "2D animated-film background painting,
  professional illustration, painterly flat colour fields with crisp edges,
  rich atmospheric light". `background_prompt(scene: &str, style: &Style)` =
  scene + style suffix + ", wide establishing shot, consistent perspective,
  an empty set: no people, no characters, no animals, no text, no watermark,
  no frame". (The workflow zeroes the negative, so the exclusions ride in the
  prose.)
- `generate(client, prompt, seed, out_png) -> Result<PathBuf>` (cached: the
  file exists → reuse).
- `split_plates(rgba) -> Plates { sky, far, mid, ground, horizon }`: Sky =
  flood from the top rows within Lab distance 18 of the top-row palette;
  horizon = lowest row where Sky still touches ≥ 30 % of the width (clamped
  0.25..0.75 of the height); Ground = everything below horizon + 2 % that is
  not part of a component rising above it; Far/Mid = remaining components,
  bottom above horizon + 3 % → Far, else Mid; hidden pixels behind Mid are
  filled from the nearest Far/Sky colour so a camera parallax shows no holes.
- `trace_plates(plates, opts) -> Scene`: four layers `Sky`, `Far`, `Mid`,
  `Ground` traced with `buzz_scene::trace` colour mode (`BackdropOptions
  { colours: 32, smoothness: 0.6, speckle: 16, bold: 0 }`; tune on the real
  image: a professional look, no posterised blotches, no slivers), layer
  depths matching AS3 (`Sky` cover, `Far` 0.85, `Mid` 0.6, `Ground` 0.0), the
  stage 1920×1080, the picture scaled to cover it.
- `save_asset(scene, library, "Backgrounds/<series>/<key>")` via
  `AssetLibrary::save`; the PNG kept beside it.
- `examples/backdrop.rs --prompt "<text>" --out <dir> [--seed N] [--style comic|painterly] [--launch] [--bitmap-only]` writes `bg.png`, `plates/*.png`, the traced asset preview `traced.png` and a 3-frame camera-pan sheet `pan.png`.
Proof the planner looks at: Ep1 "Chhotu's tea stall, village lane, morning"
in comic style and the kalwa night village in painterly style; traced vs
generated side by side at 1:1 and 3×. Touches only new files + `lib.rs`.

### P4 — Cast from a folder of character art (`crates/buzz-app/src/cast_build.rs`, new)

Generalises `series_setup.rs` (`one_view` / `build_corrected` / `relax_arms`
/ `bake_pose`) into the library:

```rust
pub struct CastRequest { pub characters_dir: Option<PathBuf> /* <dir>/<Name>/*.png, <dir>/<Name>.png, or files named "<Name> back.png" */, pub wanted: Vec<CharacterBrief> /* from P1; names + descriptions */, pub style: Style, pub replace: bool, pub comfy: Option<ComfyClient> /* to draw missing characters */, pub out: PathBuf }
pub struct CastReport { pub built: Vec<(String /* script name */, String /* Cast rig name */, PathBuf /* preview */)>, pub generated: Vec<(String, PathBuf)>, pub skipped: Vec<(String, String)>, pub spill: Vec<(String, f64 /* beyond-1px px */, f64 /* max px */)> }
pub fn build_cast(assets: &AssetLibrary, req: &CastRequest, progress: &mut dyn FnMut(&str)) -> CastReport
```

Each image → one layer rig (`RigKind::Layers`, recommended trace settings =
`TraceCharacterOptions::default()` as the dialog's Reset gives; arms relaxed
as series_setup does; `slim_rig` as the episode does), saved to `Cast/<Name>`
(`<Name> 3-4`, `<Name> Back`, `<Name> Side` by filename words
`back|side|3-4|34|three`; else front). Existing rigs kept unless `replace`.
Spill measured as `rig_vs_source` does (lift the measurement into
`buzz_app::rig_check` **only** if it is a plain move; else call the example's
code path through a function it exposes); gate ≤ 150 beyond 1 px, ≤ 3 px max;
a failed gate retries once with `speckle` doubled, and the report says so.
A character in `wanted` with no image and importance ≤ 2 is drawn by ComfyUI:
prompt "character design sheet of {description}, full body, standing in a
T-pose with arms straight out, front view, facing the camera, feet apart, {style suffix}, clean
line art, flat colours, plain white background, no shadow, no text", 1024×1536
(base 768×1152 when hq), saved `<out>/characters/<Name>.png`, then built like
any image. Proof: `examples/cast_build.rs --dir <chars> --out <dir> [--names A,B] [--replace] [--assets <lib>]` on the Ep1 folder into a **scratch asset library** (never the user's Cast without `--assets`), previews looked at; one generated character for a name with no folder ("Conductor").

### P5 — Shots, camera and lights in the episode (`episode.rs`, `buzz-act`)

- `SceneSet.shots: Vec<ShotSpec { at_line: usize, kind: String, on: Option<String>, hold: Option<f64> }>` and `"shots": "auto"`. Auto: wide for the first 2 s; a **medium on the speaker** for any line ≥ 4 s when ≥ 2 characters are on stage (cut, not move; the frame = speaker's figure from knees up, keeping the other speaker in frame when within 0.35 of the stage width); back to wide after the line; never more than one cut per 3 s; a slow 3 % push-in on a wide shot that holds > 10 s. Through the scene's `CameraTrack` keys (`scene.camera_mut()`), so the camera export already handles it; captions ignore the camera (they are screen-space already).
- `SceneSet.lighting: { key, from, warm }` from P1: `sun` → `Light::sun()` with azimuth from `from` and elevation by setting (daylight 55°, sunset 15° warm); `lamp` → `Light::lamp` at the stage top on the `from` side, warm; `moon` → cool sun 30°, lower ambient; `window` (interior) → a lamp just outside the frame on the `from` side; `none` → the setting's ambient only. Only when `lit` is on (default), only through the existing `buzz_light` kinds.
- Breathing idle, blinks and gestures stay as they are; the review checks they still run on layer rigs with the camera keyed.
Proof: `episode_build` on Ep1 scene 4 with a casting carrying `"shots": "auto"` and a `lighting`, stills at the cut frames, before/after of the lit set.

### P6 — The producer (`crates/buzz-app/src/produce.rs`, `examples/produce.rs`, dialog, agent tool)

```rust
pub struct ProduceRequest { pub script: PathBuf, pub audio: Option<PathBuf>, pub characters_dir: Option<PathBuf>, pub style: Style, pub series: String, pub out: PathBuf, pub scenes: Option<Vec<u32>>, pub assets: Option<PathBuf>, pub size: (f64, f64), pub fps: f64, pub backgrounds: bool /* generate (true) or dress from assets only */, pub mp4: bool, pub launch_comfy: bool, pub offline: bool }
pub enum Step { Parse, Breakdown, Cast, Backgrounds, Audio, Build, Render, Report }
pub fn produce(req: &ProduceRequest, progress: &mut dyn FnMut(Step, &str), cancel: &dyn Fn() -> bool) -> Result<ProduceReport>
```

Resumable: `<out>/produce.json` records each finished step with its inputs'
hashes; a re-run skips finished steps whose inputs are unchanged (`--fresh`
redoes all). Order: parse → breakdown (`breakdown.json`) → cast (P4;
`cast.json`) → backgrounds (P3, one per `location_key`, `backgrounds/`) →
audio (P2, `audio.json`) → casting (`casting.json` from `casting_value` +
background assets + props from the index + shots auto + lighting) → build
(`build_episode`, `<series>.buzz`) → render (per-scene mp4 through
`headless::render` with the scene's sound, joined with `buzz_export::film`
into `<series>.mp4`) → `report.md` (what was cast, generated, aligned,
skipped, and every warning). Progress lines go to the Tasks panel.
UI: **File ▸ AI ▸ Produce Episode…** (`Command::ProduceEpisode`) → a dialog in
`buzz-ui` (script file, audio file (optional), characters folder (optional),
style preset + free text, series name, output folder, scenes, checkboxes
"generate backgrounds with ComfyUI", "start ComfyUI if it is not running",
"render MP4") → one `TaskKind::Ai` task with Cancel; on success the `.buzz`
opens. Agent tool `produce_episode {script, audio?, characters?, style?, out}`
in `AGENT_TOOLS` + bridge schema. CLI: `examples/produce.rs --script … [--audio …] [--characters …] [--style comic|painterly|"text"] [--series Name] --out … [--scenes 4-6] [--no-backgrounds] [--mp4] [--launch-comfy] [--offline] [--fresh]`.

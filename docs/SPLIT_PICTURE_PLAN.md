## What exists (reuse; do not rebuild)

- `backdrop::split_plates(&RgbaImage) -> Plates` — Sky / Far / Mid / Ground by
  depth (P3, accepted 2026-10-14).
- `bg_objects::extract_objects(picture, plates, &ObjectOptions) -> ObjectCut` —
  VLM lists objects with boxes (`decompose_scene_image`; Claude API server when
  `ai_config::use_claude()`, else LM Studio), SAM 2 masks each, each traced into
  its own symbol scene, plate chosen by its bottom edge, hole filled from the
  surroundings. People/animals skipped. `max_objects` 8. AN3: built, **never run
  live**.
- `bg_objects::add_to_scene(cut, scene, location, size)` — each object a library
  symbol `<location> <Label> <n>` on its own layer `BG <Label> <n>` above its plate,
  mapped from picture pixels onto the 1920 × 1080 `backdrop::STAGE`.
- `backdrop::trace_plates(plates, opts) -> Scene` — layers `Sky`, `Far`, `Mid`,
  `Ground`. Producer chain to copy: `produce.rs` ~1050–1075.
- Merge a built scene into the document: `Scene::merge(&other, ImportTarget)`
  (`buzz-scene/src/merge.rs:232`, renumbers ids, brings library symbols).
- AI tasks: `App` + `TaskKind::Ai` + `AiResult` channel (`app.rs` ~580, the
  Character-from-Image task ~11040); AI commands are intercepted in
  `App::dispatch` (~8616) before `Editor::run`.

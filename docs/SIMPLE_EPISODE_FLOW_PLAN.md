# Simple episode flow (2026-11-03)

User's flow, in their words: add an audio → background with ComfyUI → trace it →
convert to layers → add my assets → place the characters, breath and eye blinks added →
one click lip sync on all characters → scripts (like Animate) do hand and body movements
while talking → scenes change without setting up again → lights, shadows, no lag →
render. First 3 parts (6–9 min) without ALAKSHMI. The FLA characters must be rigged
right; AI renames layers by body part; same for the blinks. The .buzz must export to FLA
for Animate.

## What exists today (menu paths checked in code 2026-11-03)

select all and delete. Also, as I had said, all the poses of a single character shall

pose on any frame."

`Symbol.set`, `Library::symbol_set`, `Scene::pick_from_set`, Properties ▸ Symbol
Instance ▸ Include… / Set / Start). The user rejected frame-label poses and
child-symbol designs before (memory: symbol sets) — do not use those.

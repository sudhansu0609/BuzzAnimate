# ⌨️ BuzzAnimate Keyboard Shortcuts & Quick Reference

> Fast lookup cheatsheet for tools, timeline controls, canvas navigation, editing, and window management.

---

## 🎨 Tool Shortcuts (Single Keys)

| Key | Tool | Description |
|:---:|---|---|
| **`V`** | **Selection** | Select fills, strokes, drag curves, move objects |
| **`A`** | **Subselection** | Edit vertices, anchor points, tangent handles |
| **`L`** | **Lasso** | Freehand regional selection; cuts merge shapes |
| **`G`** | **Magic Wand** | Contiguous color selection with tolerance |
| **`Q`** | **Free Transform** | Rotate, scale, skew, move transform pivot |
| **`P`** | **Pen** | Draw precise cubic Bézier paths and curves |
| **`T`** | **Text** | Place text and title boxes *(planned)* |
| **`N`** | **Line** | Draw straight lines (`Shift` for 45° snaps) |
| **`R`** | **Rectangle** | Draw rectangles (`Shift` for square) |
| **`O`** | **Oval** | Draw ellipses (`Shift` for circle) |
| **`Y`** | **Pencil** | Freehand strokes with smoothing modes |
| **`B`** | **Brush** | Fluid, Normal, Soft, Pattern, Art, Effect, Wave |
| **`M`** | **Bone** | Rigging skeletons & FABRIK inverse kinematics |
| **`W`** | **Asset Warp** | Puppet mesh deformation pins (MLS) |
| **`J`** | **Motion Path / Mode** | Draw motion paths / Toggle Object Drawing mode |
| **`K`** | **Paint Bucket** | Fill enclosed vector regions with gap detection |
| **`S`** | **Ink Bottle** | Apply or replace stroke colors and widths |
| **`I`** | **Eyedropper** | Sample colors and styles from stage |
| **`E`** | **Eraser** | Erase fills, strokes, or both |
| **`C`** | **Camera** | Pan, zoom, roll, pitch & yaw 3D camera |
| **`H`** | **Hand** | Pan canvas without deselecting (`Space + Drag`) |
| **`Z`** | **Zoom** | Zoom in (`Alt` click to zoom out) |

## ⏱️ Timeline & Animation Controls

| Shortcut | Action |
|---|---|
| **`F5`** | **Insert Frame** (extends the previous drawing) |
| **`Shift + F5`** | **Remove Frame** (deletes span, shortening time) |
| **`F6`** | **Insert Keyframe** (duplicates previous drawing) |
| **`Shift + F6`** | **Clear Keyframe** (turns keyframe into extended span) |
| **`F7`** | **Insert Blank Keyframe** (starts fresh drawing) |
| **`Alt + Backspace`** | **Clear Frames** (empties content within span) |
| **`Ctrl + Alt + X`** | **Cut Frames** |
| **`Ctrl + Alt + C`** | **Copy Frames** |
| **`Ctrl + Alt + V`** | **Paste Frames** |
| **`Enter`** | **Play / Pause** animation playback |
| **`.` (Period)** | Step 1 frame **Forward** |
| **`,` (Comma)** | Step 1 frame **Backward** |
| **`Home`** | Jump to **First Frame** |
| **`End`** | Jump to **Last Frame** |
| **`Alt + Shift + O`** | Toggle **Onion Skinning** |
| **`Ctrl + Alt + N`** | **New Layer** |
| **`Ctrl + Alt + F`** | **New Layer Folder** |

## 🔍 Canvas Navigation & Zoom

| Shortcut | Action |
|---|---|
| **`Spacebar + Drag`** | **Pan Stage** smoothly |
| **`Middle-Click Drag`** | **Pan Stage** from any active tool |
| **`Mouse Wheel`** | **Smooth Zoom** centered directly on cursor |
| **`Ctrl + =` / `Ctrl + -`** | Zoom In / Zoom Out in stepped increments |
| **`Ctrl + 1`** | **100% Actual Size** |
| **`Ctrl + 2`** | **Show Frame** (fit canvas stage bounds) |
| **`Ctrl + 3`** | **Fit in Window** (fit all contents to view) |
| **`Ctrl + Shift + W`** | **Show All** objects on stage and pasteboard |

## ✂️ Selection, Grouping & Symbols

| Shortcut | Action |
|---|---|
| **`Ctrl + Z`** | **Undo** |
| **`Ctrl + Shift + Z` / `Ctrl + Y`** | **Redo** |
| **`Ctrl + X`** | Cut |
| **`Ctrl + C`** | Copy |
| **`Ctrl + V`** | Paste |
| **`Ctrl + Shift + V`** | Paste in Place |
| **`Ctrl + D`** | Duplicate selection |
| **`Ctrl + A`** | Select All |
| **`Ctrl + Shift + A`** | Deselect All |
| **`Ctrl + G`** | **Group** selection |
| **`Ctrl + Shift + G`** | **Ungroup** selection |
| **`Ctrl + B`** | **Break Apart** (shapes, text, symbols, object drawing) |
| **`F8`** | **Convert Selection to Symbol** |
| **`Ctrl + F8`** | **New Symbol** (blank) |
| **`Ctrl + E`** | **Edit Symbol in Place** |
| **`Ctrl + F4`** | **Exit Symbol** (return to parent document) |
| **`Arrow Keys`** | Nudge selection by 1 px |
| **`Shift + Arrow Keys`** | Nudge selection by 8 px |
